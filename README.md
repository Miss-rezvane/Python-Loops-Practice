# Python Loops Practice

This repository contains three simple Python programs created to practice `for` loops.

## Projects
1. **Even Numbers**: Prints even numbers from 2 to 10.
2. **Reverse Countdown**: Prints numbers from 5 to 1 in reverse order.
3. **Star Pyramid**: Takes a number `n` and prints a pyramid of stars.

## How to run

```bash
python main.py
